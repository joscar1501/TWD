¿Qué es GitHub?

¿Qué necesitamos?

Para crear nuestra página necesitamos:

Una cuenta de GitHub. Un repositorio. Un archivo index.html. Opcionalmente, archivos CSS y JavaScript. Una conexión a Internet.
